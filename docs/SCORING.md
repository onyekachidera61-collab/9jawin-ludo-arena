# Scoring

Movement earns one point for every board-space advanced.

For each token:

- Not home: contribution = movement points
- Home: contribution = movement points x 2
- The home multiplier is applied exactly once

Entering the board does not add a special entry bonus beyond the actual movement distance.

Standard scoring does not add an arbitrary capture bonus.

The server persists score-affecting events so the final score can be replayed and independently audited.
